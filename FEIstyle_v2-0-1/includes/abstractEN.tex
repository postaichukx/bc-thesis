This thesis studies Bitcoin transaction classification using
the Elliptic dataset. It explains how to construct a transaction
graph, how the labels were assigned, and what limits the use of the
published features. The practical objective is to develop a script
that retrieves transactions and their neighbors for a specified
range of blocks, computes features from public records, and
applies a saved model. The proposed evaluation compares a model
using the original Elliptic features with one using features
computed from the blockchain. Predictive performance is to be
measured on a temporally separate set of labeled transactions.
